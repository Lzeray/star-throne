# Как запустить «Звёздный трон»

Этот файл для тебя. Перед публикацией его можно удалить.

## 1. Создай репозиторий

На GitHub: **New repository** → имя, например `star-throne` → **Public**. Галочку «Add a README» не ставь.

## 2. Залей файлы

Проще всего через git (папку `.github` веб-загрузка иногда теряет, а без неё ничего не заработает):

```bash
cd star-throne
git init
git add .
git commit -m "👑 The realm is founded"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИК/star-throne.git
git push -u origin main
```

## 3. Разреши Action писать в репозиторий

**Settings → Actions → General → Workflow permissions → Read and write permissions → Save.**

## 4. Первый запуск

Вкладка **Actions** → слева **Star Throne** → **Run workflow**. Через минуту в репозитории появятся коммит, папка `data/` и обновлённый README.

Дальше всё работает само:
- новая звезда запускает битву через 1–2 минуты;
- раз в час идёт полный пересчёт: снятые звёзды, выросшие звёзды у претендентов, «взросление» аккаунтов.

## 5. Настройки (`throne.config.json`)

| Поле | Что делает |
|---|---|
| `leagues` | названия, эмодзи, цвета и границы лиг в годах (`maxYears: null` означает «без верхней границы») |
| `excludeOwner` | `true`: твоя собственная звезда не участвует. Поставь `false`, если хочешь играть сам |
| `exclude` | список ников, которых не пускать к трону |
| `refreshHours` | как часто пересчитывать звёзды обычных претендентов (правители пересчитываются каждый запуск) |
| `title`, `tagline` | надписи на баннере |

## Как устроено

- `scripts/throne.mjs` — вся логика, без зависимостей: через GitHub GraphQL API берёт список старгейзеров, считает у каждого сумму звёзд на его собственных публичных репозиториях (без форков), раскладывает всех по лигам по возрасту аккаунта и решает, кто правит.
- `data/throne.json` — летопись: кто и когда правил, все смены власти. Хранится в git.
- Кеш посчитанных звёзд лежит в кеше GitHub Actions, а не в git, чтобы репозиторий не пух от ежечасных коммитов.
- Коммит появляется только когда что-то изменилось, и заголовок коммита сам по себе новость: «⚔️ @alice overthrew @bob…».

## Как раскрутить

1. Перед анонсом попроси 5–10 знакомых с разным возрастом аккаунтов поставить звёзды, чтобы троны не стояли пустыми.
2. Опубликуй: Show HN («Show HN: A GitHub repo where the stargazer with the most stars rules»), Reddit r/github и r/programming, X/Twitter, Хабр.
3. Лучший контент для постов — события: «новичок с 3 звёздами правит лигой Hatchlings уже 10 дней», «кто сбросит @кого-то-известного».
4. Отмечай в постах нынешних королей. Им приятно, и они сами будут делиться.
